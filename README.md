## Overview

The FTB App installs and updates Feed the Beast Minecraft modpacks with a one-click launcher, automatic Java management, instance isolation, and cloud sync for saves and settings.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **FTB App** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Modpack Library** | Browse and install the full FTB modpack catalog in one click |
| **Java Manager** | Downloads and isolates the correct Java version per modpack |
| **Instance Isolation** | Each pack runs in a separate profile preventing file conflicts |
| **Cloud Sync** | Sync modpack settings and world saves via FTB account |
